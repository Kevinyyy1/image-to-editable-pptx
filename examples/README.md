# Examples

This directory intentionally contains no third-party screenshots or generated presentation binaries.

To add a reproducible example, create a separate subdirectory containing:

```text
example-name/
├── source.png
├── scene.json
├── expected-notes.md
└── preview.png
```

Do not commit the generated `.pptx`; attach it to a GitHub release when a binary example is useful.

Only add source images that you created or have permission to redistribute. Remove personal and confidential information.

Suggested test categories:

- clean business slide with native text and cards;
- table or chart with recoverable values;
- photo-heavy editorial layout;
- dense collage with overlapping crops;
- hand-drawn arrows and underlines;
- CJK text and font substitution;
- small-text case using targeted OCR.
